# i18n Architecture Documentation

## Overview
The system implements full multilingual support for 13 Indian languages:
1. `en` - English (fallback)
2. `hi` - Hindi
3. `ta` - Tamil
4. `pa` - Punjabi
5. `gu` - Gujarati
6. `or` - Odia
7. `bn` - Bengali
8. `kn` - Kannada
9. `as` - Assamese
10. `te` - Telugu
11. `ml` - Malayalam
12. `ur` - Urdu (RTL)

## Architecture

### 1. Language Model (`core.Language`)
Stores registered language metadata (`code`, `name`, `is_rtl`, `is_active`).

### 2. Master Data Content Translation (`core.FieldTranslation`)
Master-data strings (item names, descriptions, groups) are stored in `FieldTranslation`:
- `model_label`: e.g. `'stock.Item'`
- `object_id`: PK of the record
- `field_name`: e.g. `'name'`
- `language`: Target language code (e.g. `'hi'`)
- `value`: Translated string
- `UNIQUE(model_label, object_id, field_name, language)` constraint.

### 3. Dynamic Serializer Resolution (`TranslatedSerializerMixin`)
`core.mixins.TranslatedSerializerMixin` resolves active request language via hierarchy:
`User.language` -> `Accept-Language` HTTP header -> `'en'` default.
On model serialization, if active language is not English, matching `FieldTranslation` entries replace translatable fields dynamically.

### 4. System & UI String Translation
Django standard `gettext` with locale files (`backend/locale/<lang>/LC_MESSAGES/django.po`).
